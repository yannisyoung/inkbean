Deine Agenten pflegen einen Garten.

Inkbean, ein Plugin für Claude Code

Aufgenommen im echten Fenster, während zwei Claude-Code-Sitzungen liefen. Vier Momente, jeweils in Echtzeit.

Inkbean holen, 7 USD Einmalkauf bei Gumroad. Updates sind kostenlos.

Wer macht was

Jede Bohne hält das passende Werkzeug: ein Buch zum Lesen, eine Gießkanne zum Schreiben, eine Hacke für Befehle. Während sie arbeitet, wachsen ihre Pflanzen.

Ein Hinweis, wenn alles fertig ist

Eine einzige Desktop-Benachrichtigung, wenn der ganze Durchlauf fertig ist, mit Anzahl und Dauer. Nicht eine pro Agent.

Hängende Agenten erkennen

Ein Hinweis, wenn ein Agent 5 Minuten still ist, denselben Aufruf 6-mal wiederholt oder dieselbe Datei bearbeitet wie ein anderer Agent.

Auch dein Hauptagent

Die Bohne mit dem Strohhut ist der Agent, mit dem du sprichst, einer pro laufender Sitzung. Sie döst unter dem Baum, bis Claude Code zu denken beginnt, zupft Unkraut, während sie denkt, und erntet bei jedem Werkzeugaufruf ein Gemüse für den Karren. Klick auf eine Bohne für ihren Beleg: gelesene und bearbeitete Dateien, ausgeführte Befehle, Fehler, Tokens, Zeit und welches Modell es ist.

Nur lesend und privat

  • Es blockiert oder ändert nie einen Werkzeugaufruf oder einen Agenten. Es schaut nur zu.
  • Kein Netzwerk. Die Gartenseite verbietet jeden Netzwerkzugriff, und das Plugin stellt keine Webanfragen.
  • Es schreibt nur in einen Ordner und speichert nie Prompts, Antworten, Befehle oder Dateiinhalte.
  • Der Quellcode liegt lesbar bei, mit 138 automatisierten Tests.

Vor dem Kauf

  • Benötigt Claude Code 2.1.302 oder neuer und einen aktuellen Browser.
  • Getestet unter macOS mit Chrome und Safari (Oktober 2026). Noch nicht unter Windows oder Linux getestet.
  • Das Gartenfenster und die README sind auf Englisch.
  • Es nutzt die Plugin-Hooks von Claude Code, die als Early Access gekennzeichnet sind; ein Update von Claude Code kann also ändern, wie es funktioniert. Dann arbeite ich an einer Lösung.
  • Die Verkaufsseite (Gumroad) ist auf Englisch, der Preis in US-Dollar.
