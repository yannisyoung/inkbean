Quién hace qué

Cada frijol sostiene la herramienta de su tarea: un libro para leer, una regadera para escribir, una azada para ejecutar un comando. Sus cultivos crecen mientras trabaja.

Un aviso al terminar

Una sola notificación de escritorio cuando termina todo el grupo, con cantidades y tiempo. No una por agente.

Detecta a un atascado

Un aviso cuando un agente lleva 5 minutos sin actividad, repite la misma llamada 6 veces o edita el mismo archivo que otro agente.

También tu agente principal

El frijol con sombrero de paja es el agente con el que hablas, uno por cada sesión abierta. Duerme la siesta bajo el árbol hasta que Claude Code empieza a pensar, arranca hierbas mientras piensa y recoge una verdura para la carreta con cada llamada a una herramienta. Haz clic en cualquier frijol para ver su recibo: archivos leídos y editados, comandos ejecutados, errores, tokens, tiempo y qué modelo es.

Solo lectura y privado

  • Nunca bloquea ni cambia una llamada a una herramienta ni a un agente. Solo observa.
  • Sin red. La página del huerto prohíbe todo acceso a la red y el plugin no hace peticiones web.
  • Escribe en una sola carpeta y nunca guarda prompts, respuestas, comandos ni el contenido de los archivos.
  • El código fuente viene legible, con 138 pruebas automáticas.

Antes de comprar

  • Requiere Claude Code 2.1.302 o posterior y un navegador actual.
  • Probado en macOS con Chrome y Safari (octubre de 2026). Aún no probado en Windows ni Linux.
