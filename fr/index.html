Qui fait quoi

Chaque haricot tient l'outil de sa tâche : un livre pour lire, un arrosoir pour écrire, une binette pour lancer une commande. Ses cultures poussent pendant qu'il travaille.

Un seul avis à la fin

Une seule notification de bureau quand tout le lot est terminé, avec le nombre et la durée. Pas une par agent.

Repérer un agent bloqué

Un avertissement quand un agent reste silencieux 5 minutes, répète le même appel 6 fois ou modifie le même fichier qu'un autre agent.

Votre agent principal aussi

Le haricot au chapeau de paille est l'agent à qui vous parlez, un par session ouverte. Il fait la sieste sous l'arbre jusqu'à ce que Claude Code commence à réfléchir, arrache les mauvaises herbes pendant qu'il réfléchit et cueille un légume pour la charrette à chaque appel d'outil. Cliquez sur un haricot pour voir son reçu : fichiers lus et modifiés, commandes lancées, erreurs, tokens, durée et modèle utilisé.

Lecture seule et confidentialité

  • Il ne bloque ni ne modifie jamais un appel d'outil ou un agent. Il se contente d'observer.
  • Sans réseau. La page du potager interdit tout accès réseau, et le plugin ne fait aucune requête web.
  • Il n'écrit que dans un seul dossier et n'enregistre jamais les prompts, réponses, commandes ni le contenu des fichiers.
  • Le code source est fourni lisible, avec 138 tests automatisés.

Avant d’acheter

  • Nécessite Claude Code 2.1.302 ou plus récent et un navigateur à jour.
  • Testé sur macOS avec Chrome et Safari (octobre 2026). Pas encore testé sur Windows ni Linux.
  • La fenêtre du potager et le README sont en anglais.
  • Il utilise les hooks de plugin de Claude Code, en accès anticipé : une mise à jour de Claude Code peut donc changer son fonctionnement. Dans ce cas, je travaillerai à une correction.
  • La page de vente (Gumroad) est en anglais, et le prix est en dollars américains.
