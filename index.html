Inkbean, a plugin for Claude Code

Recorded from the real window while two Claude Code sessions ran. Four moments, each at real speed.

Get Inkbean, $7 One-time purchase on Gumroad. Updates are free.

See who is doing what

Each bean holds the tool for the job: a book to read, a watering can to write, a hoe to run a command. Its crops come up while it works.

Hear when they are done

One desktop notification when the whole batch finishes, with counts and time. Not one per agent.

Catch a stuck one

A heads-up when an agent goes quiet for 5 minutes, repeats the same call 6 times, or edits a file another agent is editing.

Your main agent too

The bean in the straw hat is the agent you talk to, one per running session. It naps under the tree until Claude Code starts thinking, pulls weeds while it thinks, and picks a vegetable for the cart with every tool call. Click any bean for its receipt: files read and edited, commands run, errors, tokens, time, and which model it is.

Read-only and private

  • It never blocks or changes a tool call or an agent. It only watches.
  • No network. The garden page forbids all network access, and the plugin makes no web requests.
  • It writes in one folder only, and never saves prompts, answers, commands or file contents.
  • The source ships readable, with 138 automated tests.

Before you buy

  • Requires Claude Code 2.1.302 or later and a current web browser.
  • Tested on macOS with Chrome and Safari (October 2026). Not yet tested on Windows or Linux.
  • The garden window is in English.
  • It uses Claude Code's plugin hooks, which are marked early access, so a Claude Code update may change how it works. If that happens I will work on a fix.
