Claude Code のプラグイン「Inkbean」

2つの Claude Code セッションを動かしている間の、実際の画面の録画です。4つの場面を実際の速さでつないでいます。

Inkbean を買う（$7） Gumroad での買い切り。アップデートは無料です。

誰が何をしているか

豆はそれぞれ仕事の道具を持っています。読むときは本、書くときはじょうろ、コマンドはクワ。働いている間に作物が育ちます。

終わったら1回だけ通知

全員の作業が終わったら、件数と時間だけのデスクトップ通知を1回。エージェントごとには鳴りません。

止まっていたら知らせる

5分間動きがない、同じ呼び出しを6回くり返す、ほかのエージェントと同じファイルを編集する。そんなときに一度だけ知らせます。

メインエージェントも畑に

麦わら帽子の豆は、あなたが話しているエージェントです。セッションごとに1体います。Claude Code が考え始めるまでは木陰で昼寝をして、考えている間は草むしり、道具を1回使うたびに野菜を1本収穫して荷車に積みます。豆をクリックすると、読んだファイル・編集したファイル・実行したコマンド・エラー・トークン・時間・モデル名が分かります。

読み取り専用・プライバシー

  • ツールの呼び出しやエージェントを止めたり変えたりしません。見ているだけです。
  • 通信しません。畑のページはすべての通信を禁止していて、プラグインも Web にアクセスしません。
  • 書き込むのは1つのフォルダだけです。プロンプト・回答・コマンド・ファイルの中身は保存しません。
  • ソースは読める形で入っていて、自動テストが138件あります。

  • 畑の画面と説明書（README）は英語です。
  • Claude Code のプラグインのフック（先行提供の機能）を使っています。Claude Code の更新で動かなくなった場合は、修正に取り組みます。
