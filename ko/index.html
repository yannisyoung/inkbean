에이전트가 텃밭을 가꿉니다.

Claude Code 플러그인 Inkbean

Claude Code 세션 두 개를 실행하는 동안 실제 창을 녹화했습니다. 네 장면을 실제 속도로 이었습니다.

Inkbean 구매하기, 7달러 Gumroad에서 한 번 결제. 업데이트는 무료입니다.

누가 무엇을 하는지

콩마다 일에 맞는 도구를 듭니다. 읽을 때는 책, 쓸 때는 물뿌리개, 명령을 실행할 때는 괭이. 일하는 동안 작물이 자랍니다.

끝나면 알림 한 번

모든 작업이 끝나면 개수와 시간만 담은 데스크톱 알림을 한 번 보냅니다. 에이전트마다 울리지 않습니다.

멈춘 에이전트를 알려요

5분 동안 움직임이 없거나, 같은 호출을 6번 반복하거나, 다른 에이전트와 같은 파일을 편집하면 한 번 알려 줍니다.

메인 에이전트도 텃밭에

밀짚모자를 쓴 콩은 당신이 대화하는 에이전트로, 세션마다 하나씩 있습니다. Claude Code가 생각을 시작할 때까지 나무 그늘에서 낮잠을 자고, 생각하는 동안에는 잡초를 뽑고, 도구를 한 번 쓸 때마다 채소를 하나 수확해 수레에 싣습니다. 콩을 클릭하면 읽은 파일, 편집한 파일, 실행한 명령, 오류, 토큰, 시간, 모델 이름을 볼 수 있습니다.

읽기 전용, 개인정보 보호

  • 도구 호출이나 에이전트를 막거나 바꾸지 않습니다. 지켜보기만 합니다.
  • 네트워크를 쓰지 않습니다. 텃밭 페이지는 모든 네트워크 접근을 막고, 플러그인도 웹 요청을 하지 않습니다.
  • 한 폴더에만 쓰며, 프롬프트, 답변, 명령, 파일 내용은 저장하지 않습니다.
  • 소스는 읽을 수 있는 형태로 들어 있고, 자동 테스트가 138개 있습니다.

구매 전에

  • Claude Code 2.1.302 이상과 최신 브라우저가 필요합니다.
  • macOS의 Chrome과 Safari에서 테스트했습니다(2026년 10월). Windows와 Linux는 아직 테스트하지 않았습니다.
  • 텃밭 창과 README는 영어입니다.
  • Claude Code의 플러그인 훅(얼리 액세스 기능)을 사용하므로 Claude Code 업데이트로 동작이 바뀔 수 있습니다. 그런 경우 수정에 나서겠습니다.
  • 판매 페이지(Gumroad)는 영어이며 가격은 미국 달러입니다.
Inkbean 구매하기, 7달러

비공식 플러그인입니다. Anthropic과 관련이 없으며 승인을 받지 않았습니다. "Claude"와 "Claude Code"는 Anthropic, PBC의 상표이며, 무엇과 함께 동작하는지 알리기 위해서만 사용합니다.
