Claude Code 外掛 Inkbean

在執行兩個 Claude Code 工作階段時錄製的真實視窗。四個片段，皆為實際速度。

誰在做什麼

每顆豆子都拿著對應的工具：讀檔拿書，寫檔拿澆水壺，執行指令拿鋤頭。工作時作物會慢慢長大。

全部完成時通知一次

整批工作完成後，只發一則包含數量和時間的桌面通知，不會每個代理都提醒。

發現卡住的代理

當某個代理 5 分鐘沒有動靜、連續 6 次重複同一個呼叫，或與其他代理編輯同一個檔案時，提醒你一次。

主代理也在菜園裡

戴草帽的豆子就是正在和你對話的代理，每個工作階段一個。在 Claude Code 開始思考之前，它在樹蔭下打盹；思考時拔草；每呼叫一次工具，就收成一棵菜放上推車。點擊任何豆子，可以查看它讀過和編輯過的檔案、執行的指令、錯誤、token 數、時間以及使用的模型。

唯讀與隱私

  • 它從不阻擋或修改任何工具呼叫或代理，只是在旁觀看。
  • 不連網。菜園頁面禁止一切網路存取，外掛也不發出任何網路請求。
  • 只寫入一個資料夾，從不儲存提示詞、回答、指令或檔案內容。
  • 附有可閱讀的原始碼和 138 個自動化測試。
